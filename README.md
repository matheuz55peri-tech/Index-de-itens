# Codex Arcano — Índice de Itens

Wiki visual de 205 itens em pixel art, organizada em seis categorias.

## Como acessar

Abra o arquivo `index.html` ou publique a branch `main` pelo GitHub Pages.

## Estrutura

- `index.html`: interface e funcionalidades da wiki.
- `assets/sprites/`: imagens PNG transparentes individuais de cada item.
- `.nojekyll`: compatibilidade com GitHub Pages.

## Edição

Os textos, nomes personalizados e favoritos são salvos localmente no navegador. Use Exportar para salvar uma cópia JSON dos seus dados.

Os nomes dos itens são provisórios; os sprites originais foram fornecidos pelo criador do repositório.
