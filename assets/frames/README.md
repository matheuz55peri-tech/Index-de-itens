# Molduras predefinidas do Codex Arcano

Este diretório contém as nove molduras que aparecem automaticamente no Ateliê de Itens (`studio.html`). Os arquivos devem estar aqui com os seguintes nomes:

1. `frame-01.png` — Nuvens Rosadas
2. `frame-02.png` — Dragão Celestial
3. `frame-03.png` — Filigrana Dourada
4. `frame-04.png` — Floresta Musical
5. `frame-05.png` — Flores de Sakura
6. `frame-06.png` — Vitral Multicolor
7. `frame-07.png` — Tulipas de Vidro
8. `frame-08.png` — Flores de Outono
9. `frame-09.png` — Jardim Ametista

Os PNGs devem manter fundo e interior transparentes. **Os usuários do site não precisam importar molduras**: o Ateliê busca estes caminhos no próprio GitHub Pages e as oferece como escolhas fixas. A opção de importar imagens no navegador é apenas para molduras adicionais.

Este README cria o diretório para facilitar o envio dos PNGs pelo GitHub.
